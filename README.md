# Hybrid_score_prediction

Введение:

Основные положения: Прогнозирование учебных результатов — задача
образовательной аналитики, объединяющая статистику, машинное обучение
и педагогику. Точный прогноз финального балла позволяет вовремя
заметить отстающих, скорректировать нагрузку и оценить сложность курса.

Назначение проекта: Создание модели, которая по баллам ученика
за первые N задач предсказывает его финальный результат на курсе,
сочетая наивную линейную экстраполяцию (baseline) и машинное обучение
(CatBoost), которое учит остаток между baseline и реальностью.

Актуальность:

Проект повышает точность прогнозирования по сравнению с линейной
экстраполяцией, автоматизирует расчёты и может учитывать
дополнительные факторы: класс ученика, темп решения задач,
профиль по темам (списки, словари, ООП, продвинутые конструкции).

Целевая аудитория:

* Ученики, студенты и преподаватели программирования
* Методисты и авторы онлайн-курсов
* Разработчики EdTech-платформ и систем адаптивного обучения
* Аналитики образовательных данных

Обзор аналогов и прототипов:
* Классические LMS-системы со встроенной аналитикой
  (Moodle, Stepik, Coursera)
* Калькуляторы прогресса на основе линейной экстраполяции
* Специализированные платформы учебной аналитики
  (например, Learning Analytics Dashboard, Khan Academy Insights)
* Готовые ML-решения без «физической» основы — только регрессия по фичам

Выбор инструментальных средств:
* Язык программирования Python
* Библиотеки: numpy, pandas, CatBoost, matplotlib
* Среда разработки: Google Colab

Использование:
1. Основной запускаемый файл — ноутбук, выполняемый в среде Google Colab.
2. Введите параметры:
   * Баллы за первые N задач курса (через пробел)
   * Класс ученика (необязательно)
3. Вывод результата:
   * Baseline-прогноз (по формуле линейной экстраполяции)
   * ML-коррекция (предсказанная ошибка baseline)
   * Итоговый гибридный прогноз финального балла
   * Процент от максимума курса
